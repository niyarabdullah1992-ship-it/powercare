# نموذج HCM المؤسسي — NiroVera

مرجع القرار: مواءمة بنية **SAP SuccessFactors / Oracle Fusion HCM** دون التخلي عن جوهر المنصة.

> **القاعدة التي لا تُكسر:** النقطة لا تُكتسب إلا بوزن مهمة **معتمدة** (أولوية × جهد).
> الوحدات والوظائف والمناصب والأهداف تُشكّل *كيف* يُحسب هذا الوزن — ولا تصبح مصدرًا ثانيًا للدرجة.

الملفات: `base44/shared/hcmDerivations.ts` · `src/lib/hcmDerivations.js` · `base44/functions/hcm/entry.ts` ·
`scripts/test-hcm-derivations.mjs`

## 2. النموذج

### 2.1 الأساس (Foundation)

```
OrgUnit (company › division › department › section › station)
  ├── costCenter / establishmentNumber  ← يُورَّثان لأقرب سلف يعلنهما
  └── effectiveFrom / effectiveTo       ← سجل مؤرَّخ

Job (code · title · family · gradeMin–gradeMax)      ← يصف العمل
Position (job × orgUnit × FTE · ref · effectiveFrom) ← مقعد واحد
Employee                                              ← الشخص

EmploymentAction (type · effectiveDate · reasonCode · note)
  → يُعاد تشغيله زمنيًا لاشتقاق: منصب الموظف وحالته في أي تاريخ
```

قرارات مقصودة:

1. **الشخص ≠ المنصب ≠ الوظيفة.** المنصب لا يشغله شخصان في اليوم نفسه (`POSITION_ALREADY_FILLED`)، والشاغر يبقى ظاهرًا بدل أن يختفي.
2. **لا حالة مخزَّنة مكرّرة.** حالة الموظف ومنصبه مشتقّان من `replayEmployeeActions` — سجل الإجراءات هو المصدر الوحيد.
3. **هجرة آمنة.** الملفات القائمة بلا سجل إجراءات تُعرض بإسناد `source: "derived"` من الدور والمحطة، مع فجوة مسمّاة `NO_POSITION_ASSIGNMENT` — لا شاشة فارغة ولا بيانات ملفَّقة.
4. **بذرة أولى.** أول قراءة تُنشئ وحدة جذر + وحدة لكل محطة (`seeded: true`) حتى يمكن إنشاء المناصب فورًا.

### 2.2 الأداء — وزن المهمة يُصعد إلى الهدف

```
attainment(task objective)  = Σ (priority × effort للمهام المعتمدة المطابقة) ÷ target
target                      = هدف مطلق في الخطة  |  أعلى وزن مُثبت بين الأقران في النطاق
attainment(ontime|hse|cover)= النسبة المشتقة نفسها المستخدمة في الصيغة العامة
score                       = Σ ( attainment_i × weight_i ) ÷ 100
```

* الخطة تُربط بـ **الوظيفة** لا بالشخص — فيرث كل من يشغلها الأوزان نفسها (نمط SAP job profile / Oracle goal plan).
* **الخطة الافتراضية = الصيغة الحالية** (مهام 50 · موعد 25 · سلامة 15 · تغطية 10)، فالوظيفة بلا خطة مخصّصة تُسجَّل كما تُسجَّل اليوم — لا انحدار.
* التخصيص يعيد توزيع الـ 100% فقط؛ لا يضيف مصدرًا جديدًا للنقاط.
* **حدّ صلب:** مجموع أهداف نوع «مهام» ≥ 40% (`TASK_WEIGHT_FLOOR`) — الجوهر محميّ بالكود لا بالنية.
* المهمة غير المعتمدة لا تدخل الحساب (`taskIsProven`) — دورة الإثبات كما هي.

### 2.3 الحوكمة

| ضابط | التطبيق |
| --- | --- |
| فصل المهام (SoD) | `SELF_ACTION_FORBIDDEN` · `SELF_RATING_FORBIDDEN` |
| سبب مُرمَّز إلزامي | `ACTION_REASON_REQUIRED` / `ACTION_REASON_INVALID` لكل نوع إجراء |
| لا محو للسجل | الإبطال (`voidAction`) بسبب مكتوب ≥ 10 أحرف — القيد يبقى |
| تدفق الدورة | `draft → open → manager_review → calibration|closed` فقط |
| معايرة محدودة | التقييم ضمن ±10 حول الدرجة المشتقة، وتعديلها يحتاج مبررًا ≥ 20 حرفًا |
| أثر تدقيق | كل طفرة تكتب `AuditLog` باسم الفاعل والسبب والقيمتين |
| ظهور الأثر | آخر 40 قيدًا (`hcm.*`) تُعاد في `list` وتُعرض في «سجل تغيّر البيانات» على `/app/org` |
| صلاحية القراءة | `list` (السجل الوظيفي الكامل) للمسؤولين فقط · `assignment` لصاحب الملف أو مديره · `objectiveBoard` يُرجع صفّ الموظف نفسه لغير المدير |
| عزل المستأجر | `companyId` إلزامي + تصفية صارمة عند القراءة والكتابة |

## 3. الشرائح المنفَّذة

| شريحة | الخادم | الواجهة |
| --- | --- | --- |
| 1 — أساس الوحدات/الوظائف/المناصب + الإجراءات المؤرَّخة | `hcm`: `list · createOrgUnit · createJob · createPosition · closePosition · recordAction · voidAction · assignment` | `/app/org` → `HcmFoundationBoard` · ملف الموظف → تبويب «المنصب والإجراءات» |
| 2 — أهداف موزونة تقودها وزن المهمة | `hcm`: `objectiveBoard · setGoalPlan` | `/app/performance` → `JobObjectiveBoard` (الصيغة ظاهرة + تفكيك لكل هدف) |
| 3 — دورات تقييم ومعايرة وحوكمة | `hcm`: `createCycle · advanceCycle · submitRating` + إعادة قيود التدقيق في `list` | `/app/performance` → `ReviewCyclePanel` · `/app/org` → «سجل تغيّر البيانات» |

التخزين: `CompanyDataBlob` بفئتين — `hcmFoundation` (وحدات · وظائف · مناصب · إجراءات) و`hcmPerformance` (خطط · دورات · تقييمات).
